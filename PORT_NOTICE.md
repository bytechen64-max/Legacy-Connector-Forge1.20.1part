# Unofficial Forge 1.20.1 port

Original project: Legacy Connector by Kyle Pitcock.
Upstream: https://github.com/kylepitcock/Legacy-Connector
Original license: MIT; the original copyright and permission notice remain in LICENSE.

Port maintained by: Forge Port Contributors.
Display name: Legacy Connector (Forge 1.20.1 Port).
This is an independently maintained port, not an upstream NeoForge release and not an upstream endorsement.
The technical mod ID remains `legacyconnector` for compatibility with existing worlds and configurations.

Changes include the Forge 1.20.1 loader/runtime adaptation and compatibility fixes for legacy rendering,
entities, blocks, API bridges, SRP meteor placement, and modern-mod detection.
Compatibility results and screenshots from NeoForge 1.21.1 do not establish compatibility on this port.

Do not redistribute users' legacy mod jars or translation caches with this project.
The publication cover under docs/release/assets is AI-generated concept artwork, not an in-game screenshot.
